# Predictive Maintenance – FactoryGuard AI

## Problem Statement
Unplanned machine failures in manufacturing cause high downtime costs.
The goal is to predict machine failure in advance using sensor (IoT/tabular) data.

## Project Objective
- Build a production-oriented ML pipeline
- Predict machine failure
- Explain predictions using Explainable AI (SHAP)

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- XGBoost
- SHAP
- GitHub
